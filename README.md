# Kotlin Neural Network Racing
An AI simulation where neural networks learn to drive.

## How to Run
1. Open this project in **IntelliJ IDEA**. (https://www.jetbrains.com/idea/download/?section=windows)
2. Ensure you have **JDK 17 or higher** installed.
3. Run the `Main.kt` file.

## Controls
All controls are listed on screen once the program is run

# Kotlin Neural Network Racing
An AI simulation where neural networks learn to drive.

## How to Run
**[Download the latest version here](https://github.com/Jayo6Mayo7/Racing_AI/releases/tag/v2.0)**\n
Go to https://adoptium.net/temurin/releases and download the Windows version\n
**During installation, make sure that the "Set JAVA_HOME variable" and "Associate .jar files" boxes are CHECKED/installed**\n
Then, open the trackmania.jar file you downloaded in the first step

## Controls
All controls are listed on screen once the program is run

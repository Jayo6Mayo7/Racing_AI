# Kotlin Neural Network Racing
An AI simulation where neural networks learn to drive.

## How to Run
**[Download the latest version here](https://github.com/Jayo6Mayo7/Racing_AI/releases/tag/v2.0)**
Go to https://adoptium.net/temurin/releases and download the Windows version
**During installation, make sure that the "Set JAVA_HOME variable" and "Associate .jar files" boxes are CHECKED/installed**
Download trackmania.jar and then open it

## Controls
All controls are listed on screen once the program is run
